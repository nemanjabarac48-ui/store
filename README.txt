POKRETANJE
1. Instaliraj PHP 8+ (ili XAMPP/Laragon).
2. U folderu kroj-store pokreni:  php -S localhost:8000
3. Otvori http://localhost:8000

SLIKE: stavi slike proizvoda u assets/img/ kao 1.jpg ... 12.jpg (omjer 3:4 ili 4:5).
PROIZVODI: uredi niz $products u includes/data.php.
PORUDŽBINE: upisuju se u orders/orders.jsonl (jedna porudžbina po liniji).
